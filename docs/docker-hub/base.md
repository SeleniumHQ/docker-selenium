# Selenium Grid Base image
## This is the base image shared across the other Selenium Grid images.

This image is not meant to be used directly as it does not provide any useful functionality.

If you are interested in trying out Selenium Grid in Docker, please check out any of these other images:
- [Standalone Firefox](https://hub.docker.com/repository/docker/selenium/standalone-firefox)
- [Standalone Edge](https://hub.docker.com/repository/docker/selenium/standalone-edge)
- [Standalone Chrome](https://hub.docker.com/repository/docker/selenium/standalone-chrome)
- [Grid Hub](https://hub.docker.com/repository/docker/selenium/hub) together with [Node Firefox](https://hub.docker.com/repository/docker/selenium/node-firefox), [Node Chrome](https://hub.docker.com/repository/docker/selenium/node-chrome), and/or [Node Edge](https://hub.docker.com/repository/docker/selenium/node-edge)
